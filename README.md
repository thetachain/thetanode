## Overview
Theta Chain is an experimental, community-driven blockchain that decentralizes GPU and cloud compute.  
It enables developers and researchers to run workloads such as AI model training, inference, and rendering across a global, trustless network.

---

## Vision
Theta Chain simplifies high-performance computation by providing:
- Access to decentralized GPU & cloud resources  
- Support for self-improving AI workloads  
- Automated, simplified processing pipelines  
- Community governance and transparent contributions  

---

## Key Features
- **Decentralized Compute:** AI, ML, rendering, and data workloads  
- **Fair Launch:** 0% premine, 0% developer fee, no pre-allocated tokens  
- **Scalable Infrastructure:** adjusts dynamically to compute demand  
- **Open Source:** community-governed, transparent, and contribution-friendly

## Tokenomics
**Token:** THETA  
**Max Supply:** ~100,000,000 THETA  *note: (Reward reduced to 0.1 for rest of chain's life after 100 mil)  
**Mining:** Ethash (GPU-mineable)  
**Premine:** 10% (5% for development team  and 5% for project launches and airdrops)   
**Dev Fee:** None

## Meaning of "Theta"
In mathematics, **θ (theta)** represents an angle.  
Theta Chain uses it metaphorically to signify reducing the "difficulty angle" of modern computational and AI challenges.
